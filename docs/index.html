SECTION 1

General

1-1.PURPOSE. This manual describes conn and its operation.

1-2.SCOPE. conn is a station for one operator directing many hands on one machine. It shows the hands working each place, the standing of each, and which hand is waiting on the operator, and it puts the operator in front of a hand. It does not edit files, run builds, or hold conversations. The hands do.

1-3.DEFINITIONS. Terms used in this manual.

OperatorThe person at the station.
HandA process working a place for the operator: a shell, an agent, or a run. Also station hand.
AgentA hand that holds a conversation and can stop to wait on the operator.
PlaceA directory hands work in: a git repository, or a folder holding several.
StandingWhat a hand is doing: WORKING, ACTIVE, IDLE, or WAITING.
WaitingThe standing of an agent stopped on something it has asked of the operator.
RailThe pane on the left, forty-four columns wide, holding the watch and the other views.
WatchThe hands, by place, in the order they began.
SlotThe pane on the right, holding one hand.
BarThe line at the foot of the window: an annunciator for the keys, and a lamp for each hand.

1-4.INDICATIONS. The station indicates two things: what each hand is doing, and which hand is waiting. The watch and the bar's lamps indicate the first. WAITING on the watch, blinking, a lamp in the owed color, and tab indicate the second.

1-5.COMMANDS. conn alone brings up the console and continues to the watch. Other commands are given by name after it. --light and --dark set the ground, ahead of a command if one is given.

SYNOPSIS

COMMANDDOES
connBrings up the console, then the watch.
conn downTakes the server down with everything in it, and reports what went.
conn theme claudeWrites conn's theme for Claude Code.
conn theme vimWrites conn's colorscheme for nvim.
conn --lightSets the ground light.
conn --darkSets the ground dark.
conn --helpPrints this table.
conn --versionPrints the build.
