THE PANEL

  • The project you are in, a row a process.
  • Rows stand by role; a row that wants you is in the accent, where it stands.
  • Under them, a line for every other project with something running.
  • The process under the cursor fills the rest of the window. enter puts the keys in it; ctrl-space brings them back.
  • q leaves. Everything keeps running.

AGENTS

  • Agents reach the same verbs from a shell, and are told so when conn starts them.
  • What an agent starts under a name is a row on the panel, with a pane you can go into and read.
  • What it waited on is a check. The rest is the stack.
  • st runs the checks as they were last run here. ss brings the stack up. Nothing is declared.
  • Every conversation conn starts is told what the project runs.

INTENT

  • conn is told nothing about what a project runs. A key names an intent. How it is carried out here is found once and kept.
  • Where the intent has been carried out through conn before, by you or by an agent, the key runs the same command again. Where it has not, conn asks Claude Code, shows the answer, and enter runs it and keeps it.
  • st asks what the checks are, and ss what the stack is. c talks to a process: a web server opens in the browser; for anything else conn asks once, psql for postgres, and keeps the answer under the row's name.
  • A kept command that fails as soon as it starts goes back to Claude Code with what it printed. A command wrong for this machine is offered corrected. One that is right, and failed on the project's own account, is left as it is.
  • aa opens a conversation about the row, with its last lines as the brief. af does the same for everything that failed. Anything the verbs do not cover is handed to an agent this way.

WAITING

  • A conversation that stops to ask is in the accent.
  • tab goes to the one that has waited longest. From inside any pane, ctrl-space then tab.
  • The band at the foot counts the conversations waiting across every project. The terminal's title says it too, and the bell rings as one more does.
