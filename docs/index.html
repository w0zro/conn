SECTION 1

General

1-1.PURPOSE. This manual describes conn and its operation.

1-2.SCOPE. conn is a station for one operator directing many hands on one machine. It shows the processes running in each project, what each is doing, and which one is waiting for the operator, and it puts the operator in front of any of them. It does not edit files, run builds, or hold conversations. The hands do.

1-3.DEFINITIONS. Terms used in this manual.

OperatorThe person using conn.
HandA process conn watches: a shell, an agent, or a command a shell is running. Also called a station hand.
AgentAn AI coding assistant running in a terminal, such as Claude Code. An agent can stop and wait for the operator to answer it.
PlaceThe project directory a hand runs in: a git repository, or a folder that holds several repositories.
StandingThe state conn reports for a hand: WORKING, ACTIVE, IDLE, or WAITING.
WaitingThe standing of an agent that has stopped and needs an answer from the operator, such as a permission or a question.
RailThe left pane of the window, forty-four columns wide. The watch and the other views are shown there.
WatchThe list of hands, grouped by place, in the order they started.
SlotThe right pane of the window. It shows one hand.
BarThe status line at the bottom of the window. It shows the state of the keys on the left and one lamp per hand on the right.

1-4.INDICATIONS. The station indicates two things: what each hand is doing, and which hand is waiting. The watch and the lamps on the bar show the first. The word WAITING on the watch, blinking, and a lamp on the bar in the same color show the second; tab goes to it.

1-5.COMMANDS. conn alone brings up the console and continues to the watch. Other commands are given by name after it. --light and --dark set the ground, ahead of a command if one is given.

SYNOPSIS

COMMANDDOES
connBrings up the console, then the watch.
conn downTakes the server down with everything in it, and reports what went.
conn theme claudeWrites conn's theme for Claude Code.
conn theme vimWrites conn's colorscheme for nvim.
conn --lightSets the ground light.
conn --darkSets the ground dark.
conn --helpPrints this table.
conn --versionPrints the build.
