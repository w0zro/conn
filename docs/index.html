SECTION 1

General

1-1. conn is a station for one operator directing many processes on one machine. It runs on tmux, which it starts and holds. The panel occupies the left of the terminal and the workspace the rest. The panel lists the processes working each project — shells, contacts, and commands — with what each is doing and which is waiting on the operator. The workspace holds the one process the operator is in. Keys move between them.

1-2. conn finds projects by walking the roots it was given: the directories named in ~/.config/conn/config.json, or in CONN_ROOTS, which is read first. It is told these and infers nothing; a conn that has been told nothing asks before it goes on.

SECTION 2

Keys

2-1. A chord is the prefix — ctrl-space, or what CONN_PREFIX names — followed by one key. A chord works from anywhere in the station, including from inside a process, because tmux takes it before the process does.

Chords

KEYACTION
prefix -The processes view, from wherever the keys are. Puts the manual away if it is up.
prefix pThe projects list.
prefix prefixThe process worked in before this one.
prefix tabThe process that has waited longest.
prefix jDown the processes conn can put in the workspace.
prefix kUp them.
prefix sA shell at the project the panel is looking at.
prefix aA contact at that project.
prefix alt-aThe sessions suspended at that project.
prefix +conn's configuration file, in an editor.
prefix ?This manual, in the workspace, with the keys in it.
prefix qDetach. The station keeps running.

2-2. The panel's own keys work while the panel has them, and are listed here as the processes view takes them. In the projects list and the sessions view a letter is typed into the line instead: there, enter takes the row under the cursor and esc goes back.

2-3. While this manual is up the keys are in it, and the status line says HELP. It scrolls with j and k, a screen at a time with space and b, and to either end with g and G. esc leaves it and puts the keys back where they were when it was asked for — in the workspace, or on the panel; prefix - leaves it for the processes view whichever it was.

The panel
