CONN MANUALGITHUB ↗

A console for the processes working your projects.

conn puts every process on one machine under the project it works, says what each project wants of you, and puts the one you choose in front of you.

$curl -fsSL https://conn.w0zro.com/install.sh | sh

macOS and Linux. Needs tmux, and lsof on macOS.

The panel: each project at the margin, what it wants of you at the end of its rule, and its processes under it, each marked for what it is. The workspace: the one process you are in. The status line: the station's band.

THE PANEL01

Every shell, editor, coding agent, dev server, container and Homebrew service working a project under your roots is a row, under the project it works. A row is marked for what it is and says what it is doing; a project's rule ends in what the project wants of you, and a project that wants nothing says nothing.

enter puts a row's process in the workspace and the keys in it. ctrl-space brings the keys back to the panel from inside any process. q detaches, and everything keeps running.

CONTACTS02

A Claude Code session is a contact. conn reads its state: WORKING while it works, WAITING once it has stopped to ask, and how long it has waited. tab goes to the contact that has waited longest. The question a waiting one asked is on its page, before you go in.

The sessions left suspended at a project are listed by A, and across every project by r; one is resumed in a pane of its own.

WHAT A PROJECT DECLARES03

A project may keep a file named .conn at its top, naming the processes that work it, one a line. What is declared and not running is a row at the foot of the block, worded DOWN. enter brings it up and goes in; u brings it up; U brings up everything the project declares. x ends it, and the row is DOWN again.

# what works this project
web frontend:          npm run dev
api:                   go run ./cmd/api
worker services/queue: make run
db:                    docker compose up postgres
cache:                 brew services start redis

A command that runs docker compose up has the services compose would bring up as rows under it. A command that runs brew services start is the Homebrew service it names, as brew reports it.

THE LOG04

l opens the log: what changed while you were in a pane. A contact that stopped to ask, a fault, a turn over, a pane that said panic or FAIL, newest first, with a note on each line. The band counts the lines since you last looked.

SERVING05

A process listening on a port carries the port on its row, and o opens it in the browser. A listener that has gone says CLOSED, rather than going missing. Services from Homebrew and compose are rows as the rest are: ACTIVE with their ports, DOWN until started.

SEARCH06

/ searches what a project's processes have written, every held pane at once. enter on a match goes into the pane that wrote it, in copy mode, on the line.
